# 完了時の総評記載

[checklist.md](checklist.md) の手順でチェックリストの全項目にチェックが
入った時点で、実行したスキル（verify-docs・dedupe-docs・tighten-docsの
いずれか）のセクション末尾に `### 総評` の見出しで以下を記載する
（省略不可。項目が1件のみの場合も書く）。

- **検査したファイル数**（`node scripts/verify-docs.mjs` の出力にある
  「文書 N 件」の N、または意味的重複チェックの対象文書数）と、見出し数・段落数・
  合計バイト数（同コマンドのJSON出力の `summary.documents`）
- **検出した違反・重複の件数**（`summary.violations.byKind` の種別ごとの内訳。0件ならその旨明記）
- **作業にかかった時間**（開始・終了時刻・所要時間）。チェックリスト
  ファイル作成時の `date` 出力（[checklist.md](checklist.md)参照）と
  総評記載時の終了時刻の差分。git 管理下なら直前コミット時刻を開始、
  この作業のコミット時刻を終了として代用してよい
  （`git log -1 --format=%ai`）
- **全体のサイズ変化**（サイズを変更した項目がある場合、下記「全体の
  サイズ変化」テーブルで合計を示す。サイズ変更が無い場合もテーブルは
  省略してよいが、「サイズ変更なし（合計 NB）」の形で検査対象文書の
  合計バイト数を明記する）
- **常時読み込み→オンデマンド化**（`entryPoints`・各 `SKILL.md` 本体は
  スキル起動のたびに常時読み込まれるのに対し、`references/` 配下・
  `docsDir` 配下は `SKILL.md` から参照された時だけ読まれる。分割に
  よって常時読み込みからオンデマンドへ移せたバイト数を下記テーブルで
  示す。該当項目が無ければ「該当なし」と明記しテーブルは省略してよい）
- **節単位の変更根拠**（サイズ変更・重複統合・リンク修正があれば、JSON出力の
  `location.headingPath` と行番号を示す。文書全体の変更であればその旨を明記する）
- **大きい節・TODO**（`summary.largestSections` と `summary.todo.entries` から、
  分割候補・残っている借金を必要な場合だけ記載する。該当なしなら「TODOなし」と明記する）

## 全体のサイズ変化

| ファイル | 圧縮前 | 圧縮後 | 差分 | 圧縮率 |
| --- | ---: | ---: | ---: | ---: |
| verify-docs/SKILL.md | 11,549B | 11,269B | -280B | 2.4%減 |
| dedupe-docs/SKILL.md | 9,932B | 6,530B | -3,402B | 34.3%減 |
| **合計** | **21,481B** | **17,799B** | **-3,682B** | **17.1%減** |

合計行の圧縮率は `(1 - 圧縮後合計 / 圧縮前合計) * 100` で計算する
（各行の圧縮率の単純平均ではない）。

## 常時読み込み→オンデマンド化

| 移動元（常時読み込み） | 移動先（オンデマンド） | 移動したサイズ |
| --- | --- | ---: |
| verify-docs/SKILL.md・dedupe-docs/SKILL.md | verify-docs/references/checklist.md | 3,881B |

```markdown
### 総評

- 検査対象: 3ファイル（verify-docs.mjs出力）
- 構造集計: 見出し 12件・段落 34件・合計 17,799B
- 検出した違反: 0件
- 作業にかかった時間: 12:40 〜 12:42（所要2分24秒）
- 全体のサイズ変化: 上記「全体のサイズ変化」テーブルの通り、
  SKILL.md 2ファイルの合計を 21,481B → 17,799B に削減（17.1%減）
- 常時読み込み→オンデマンド化: 上記テーブルの通り、3,881B分の内容
  （チェックリスト作成手順）を常時読み込みからオンデマンドへ移動
```

サイズ変更が無い回の記載例:

```markdown
- 全体のサイズ変化: サイズ変更なし（合計 17,799B）
```
