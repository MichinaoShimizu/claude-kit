# オブジェクトの名称・参照規約

[verify-docs スキル](../SKILL.md)から参照される。和名・英名・ファイル名を
組にして定義するオブジェクトを、文書群で同じ呼称として扱うための規約である。

## 対象

対象は、実行可能スクリプト・設定ファイル・生成物など、和名・英名・ファイル名を
組にして定義するオブジェクトに限る。和名だけを持つ一般概念、ファイルを持たない
JSON の値、コマンド中のパスそのものには適用しない。

## 定義文書での記載

オブジェクト自体を定義する文書では、対象の説明より前に、次の3項目を示す。

| 項目 | 記載する値 |
| --- | --- |
| 和名 | 日本語の正称 |
| 英名 | 識別子・製品名などの英語の正称 |
| ファイル名 | リポジトリからの相対パス |

定義文書では、この表または同じ情報を持つ箇条書きで3項目を一組として記載する。
後続の本文では和名で呼ぶ。英名とファイル名を本文で繰り返さない。

## 他文書からの参照

定義文書以外では、和名を正称とする。初出だけでなく、オブジェクトを指す呼称は
常に、定義文書の該当箇所へリンクした和名で記載する。

```md
[文書構造検証器](docs/structure.md#文書構造検証器)
```

英名・ファイル名を呼称として併記したり、他文書で3項目を再定義したりしない。
ただし、実行手順のコードブロック、設定例、実在性を示すパスのように、ファイル名
そのものが必要な箇所ではバッククォート内に記載してよい。この例外は、呼称を英名・
ファイル名へ切り替えることを意味しない。
