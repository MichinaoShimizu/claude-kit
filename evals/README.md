# スキル判断の評価セット

`dedupe-docs` と `tighten-docs` の意味判断を比較するための小規模な評価セット。
CIの pass/fail には使わない。スキルの指示、モデル、評価方法を変えるときに、
同じ入力に対する判断を人またはエージェントがレビューする。

この評価セットはパッケージ開発用であり、導入器は導入先へコピーしない。

各ケースは入力文書、期待する判断、失ってはいけない事実、レビュー質問を持つ。期待する
判断は生成文の完全一致ではなく、`consolidate`・`ask-human`・`tighten`・`leave-unchanged`
のいずれを選ぶべきかを表す。

更新時は、ケースを増やす理由とレビュー結果をPRに記録する。実文書の内容や利用者情報を
入れず、最小限の合成fixtureだけを置く。
