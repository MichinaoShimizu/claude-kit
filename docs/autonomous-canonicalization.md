# 自律正本化モード

`dedupe-docs` は既定では、内容を変えずに既存の正本とポインタを選ぶ。利用者が
`自律正本化モード`、または「正本性を優先して文書間の統合・削除まで自律的に完走して」
のように明示した場合だけ、自律正本化モードで実行する。対象・目標・禁止事項が利用者から
指定されている場合は、それらを優先する。

## 既定のモード

既定では[正本候補の選定規約](canonical-selection.md)の `auto-canonical` 条件を満たす場合だけ、
既存の詳細文書を正本にして他方をポインタへ置換する。意味、対象読者、条件、例外、手順、
数値、コマンド、参照先を保てると確信できない候補は、利用者に質問する。回答があるまで
候補を是正済みにせず、保守報告へ統合しない。

## 自律正本化モード

正本性と読者経路を高めるため、文書間の内容統合、ポインタ化、新たな正本文書の作成、
統合済み不要文書の削除を行える。意味が重なる範囲や配置先に多少の判断リスクがあっても、
その不確実性を理由に利用者の回答待ちで停止しない。対象内の候補を処理し、検査と記録まで
完走する。無回答の `回答待ち` を残さない。

実施前に、元文書、統合先、各文書だけにある対象読者・条件・例外・手順・数値・コマンド・
参照先、正本へ向くリンクを一時作業記録へ列挙する。既存文書のどれも全情報を置く場所として
適さない場合は、既存の文書構成と読者の入口に合わせた新しい正本文書を作る。正本には元文書の
固有情報を統合し、入口文書には必要な導線を残す。

不要文書を削除できるのは、次を全て満たす場合だけである。

- 削除対象だけにあった情報を正本へ統合済みである
- 正本または残すポインタへ向けて、削除対象へのリンクと断片リンクを更新済みである
- 削除しても対象読者の入口と必要な導線を失わない
- `node scripts/document-structure-verifier.mjs` でリンク切れ・孤立文書・サイズ超過・
  機械的重複がない

自律正本化モードでも、事実を捏造しない。法的・安全上の注意、契約上の義務、利用者が明示した
数値・コマンド・設定値は削除・変更しない。`allow-duplicate` マーカーを自分で追加せず、
対象外の文書を変更しない。これらを守ったまま統合できない情報は残し、未完了にはせず理由を
記録する。

一時作業記録と保守報告に `実行モード: 自律正本化`、元文書、正本、作成・削除した文書、
移動した内容、残したリスク、保護対象、最終検査結果を記録する。全対象を統合、ポインタ化、
削除または保護対象として記録し、`node scripts/document-structure-verifier.mjs` が
「文書構造: すべて通過」で終われば完了とする。

既定モードとの正本化・削除・必須事実の結果を比べる場合は、同じ入力スナップショットから
[モード比較](mode-comparison.md)を実施する。
