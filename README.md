# claude-kit

Claude Code などの生成AIエージェント向けに作った、リポジトリに入れて使う
再利用可能なパッケージの置き場所。スキル（.claude/skills 配下）だけでなく、
専用のサブエージェント（.claude/agents 配下）を伴うものも同じ形で置く。
1パッケージ1ディレクトリで、コピー元はこのリポジトリの各ディレクトリそのもの。

| パッケージ                  | 何をするか                                                                                                                |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [verify-docs](verify-docs/) | CLAUDE.md・AGENTS.md・README・docs のような階層的な文書群を「必要な時にだけ読まれる」構造に保つ（参照整合性・サイズ予算・重複検知） |

## 使い方

対象のリポジトリに、使いたいパッケージのディレクトリの中身をそのままコピーする。
詳しい入れ方・CI への差し込み方は各パッケージの README（例:
[verify-docs/README.md](verify-docs/README.md)）を見る。

## 1パッケージ = 1フォルダ

各パッケージは自分のフォルダの中に、必要なものを全部持つ（スキル本体・
専用サブエージェント・付属スクリプト・README など）。**スキルだけの
パッケージもあれば、専用のサブエージェントを伴うパッケージもある。** コピーする側は
フォルダごと持っていけば、構成要素が一緒についてくる形にする
（一部だけ持っていって動かない、という事故を防ぐ）。

## このリポジトリ自身の CI

各パッケージは、自分自身のディレクトリに対して自分自身の検査を適用する
（ドッグフーディング）。加えて、リポジトリ直下（README.md・CLAUDE.md）にも
verify-docs をかける。[.github/workflows/ci.yml](.github/workflows/ci.yml) が
これらを走らせる。新しいパッケージを足したら、そのパッケージが自己検査できるなら
ここにも1行足す。
